這一個文章介紹:數字刪去法

 以下用9*9這一個Category來解說。

 實際操作:在一個空白格子裡，有1、2、3、4、5、6、7、8、9這9種可能性，
 如果在一個空白格子中，有其中8種可能性被刪去，那麼剩下那一種可能性將是此空白格子填入的數字。

 「這裡給的例子都是確定填入9」 第1頁:因為在同一列(row)裡面有1、2、3、4、5、6、7、8已經填入，所以在同一列(row)中只剩餘一個可能性(9)，可以將數字9填入該格。 第2頁:因為在同一行(column)裡面有1、2、3、4、5、6、7、8已經填入，所以在同一行(column)中只剩餘一個可能性(9)，可以將數字9填入該格。 第3頁:因為在同一區塊裡面有1、2、3、4、5、6、7、8已經填入，所以在同一區塊中只剩餘一個可能性(9)，可以將數字9填入該格。 第4頁:可以利用不同數字指向同一格的方式得出唯一可能性。
 "重點提醒，在解少數字的此類數獨的時候，有時會遺漏這個可能性。
